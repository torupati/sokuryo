# 二重ステレオ投影（現場座標変換）仕様書

EPSG Guidance Note 7-2 の Oblique Stereographic（method 9809）に、現場座標系への回転を加えたもの。
本書の式で書いた参照実装は、往復誤差 1e-12° 以下を確認済み。

## 1. 記号と単位

| 記号 | 意味 | 単位 |
|---|---|---|
| a = 6378137.0 | GRS80 長半径 | m |
| f = 1/298.257222101 | GRS80 扁平率 | – |
| e² = f(2−f), e = √e² | 第一離心率（e ≈ 0.0818191910428158） | – |
| φ, λ | 対象点の緯度、経度 | **rad** |
| φ0, λ0 | 投影原点の緯度、経度 | rad |
| k0 | 原点でのスケール係数 | – |
| FE, FN | 原点の E, N 座標（false easting / northing） | m |
| θ | 現場座標の回転角 | rad |

- 角度は内部では常に rad。
- e は定数を直書きせず、f から計算する。

## 2. 原点パラメータの前計算

φ0, k0 が決まれば一定。キャッシュできる。

```
ρ0 = a(1−e²) / (1 − e² sin²φ0)^(3/2)
ν0 = a / √(1 − e² sin²φ0)
R  = √(ρ0 ν0)                          … 等角球の半径
n  = √(1 + e² cos⁴φ0 / (1 − e²))

S1 = (1 + sinφ0) / (1 − sinφ0)
S2 = (1 − e sinφ0) / (1 + e sinφ0)
w1 = (S1 · S2^e)^n
sinχ0 = (w1 − 1) / (w1 + 1)

c  = (n + sinφ0)(1 − sinχ0) / ((n − sinφ0)(1 + sinχ0))
w2 = c · w1
χ0 = asin((w2 − 1) / (w2 + 1))         … 原点の等角緯度
Λ0 = λ0
```

## 3. 順変換（緯度経度 → 現場座標）

入力は (φ, λ) とパラメータ一式。

```
Sa = (1 + sinφ) / (1 − sinφ)
Sb = (1 − e sinφ) / (1 + e sinφ)
w  = c · (Sa · Sb^e)^n
χ  = asin((w − 1) / (w + 1))           … 等角緯度
Λ  = n (λ − λ0) + Λ0                   … 等角経度

B  = 1 + sinχ sinχ0 + cosχ cosχ0 cos(Λ − Λ0)
x  = 2 R k0 cosχ sin(Λ − Λ0) / B                                    … 原点からの東距離
y  = 2 R k0 (sinχ cosχ0 − cosχ sinχ0 cos(Λ − Λ0)) / B              … 原点からの北距離
```

回転は原点 (FE, FN) まわりで **−θ** だけ回す。

```
E = FE + x cos(−θ) − y sin(−θ) = FE + x cosθ + y sinθ
N = FN + x sin(−θ) + y cosθ     = FN − x sinθ + y cosθ
```

## 4. 逆変換（現場座標 → 緯度経度）

### 4.1 逆回転

順変換の回転（−θ）を打ち消すため、+θ だけ回す。

```
dE = E − FE,  dN = N − FN
x  = dE cosθ − dN sinθ
y  = dE sinθ + dN cosθ
```

### 4.2 等角球上の (χ, Λ) を求める

```
g = 2 R k0 tan(π/4 − χ0/2)
h = 4 R k0 tanχ0 + g
i = atan2(x, h + y)
j = atan2(x, g − y) − i
χ = χ0 + 2 atan( (y − x tan(j/2)) / (2 R k0) )
Λ = j + 2 i + Λ0
```

EPSG の式は atan。h + y > 0 かつ g − y > 0 の範囲では atan2 と同じ値になる。範囲外でも壊れないよう atan2 を推奨。

### 4.3 経度

```
λ = (Λ − Λ0) / n + Λ0
```

### 4.4 測地緯度の反復解法

```
ψ  = 0.5 · ln( (1 + sinχ) / (c (1 − sinχ)) ) / n       … 目標の等長緯度

φ_1 = 2 atan(e^ψ) − π/2                                  … 初期値
反復 i = 1, 2, …:
    ψ_i      = ln( tan(φ_i/2 + π/4) · ((1 − e sinφ_i) / (1 + e sinφ_i))^(e/2) )
    Δ        = (ψ_i − ψ) · cosφ_i · (1 − e² sin²φ_i) / (1 − e²)
    φ_(i+1)  = φ_i − Δ
    |Δ| < 1e-12 [rad] で終了、最大 20 回
```

旧 C++ 実装（`stereo_projection.cpp` の `Reverse` / `ReverseFast`）との違い:

- 補正項は `(1 − e² sin²φ_i)`。`cos(...)` で包んではいけない。
- ψ は毎回、その時点の φ_i から計算する。1ステップ遅れて使ってはいけない。

正しい式では 3〜4 回で収束する。旧実装は 54 回反復しても、緯度 26°〜43° で約 1.5〜2.2 mm の誤差が残った。

## 5. API 定義（言語非依存）

### 型

```
Ellipsoid  { a: f64, f: f64 }                  // 既定: GRS80
SiteParams {                                   // 現場（ローカライゼーション）パラメータ
    origin_lat:  f64,   // φ0 [rad]
    origin_lon:  f64,   // λ0 [rad]
    false_east:  f64,   // FE [m]
    false_north: f64,   // FN [m]
    scale:       f64,   // k0（> 0）
    rotation:    f64,   // θ [rad]
}
LatLon { lat: f64, lon: f64 }                  // rad
EN     { east: f64, north: f64 }               // m
```

### 関数

```
StereoProjection::new(ellipsoid, params) -> Result<StereoProjection, Error>
    // §2 の前計算を行い保持する。以降のメソッドは状態を変更しない（スレッドセーフ）。

forward(&self, p: LatLon) -> Result<EN, Error>
    // §3

inverse(&self, q: EN) -> Result<LatLon, Error>
    // §4。収束しなければ Error::NotConverged

forward_once(lat, lon, params) -> Result<EN, Error>
inverse_once(east, north, params) -> Result<LatLon, Error>
    // 単発変換用。内部で new を呼ぶ。

deg_to_rad(x), rad_to_deg(x)
```

### 設計方針

- 単位は入出力とも rad に統一する。旧 `Reverse` は deg を返していて `Forward` と非対称だった。
- 引数の並びは (lat, lon) に統一する。旧 `Forward` は対象点が (lon, lat)、原点が (lat, lon) だった。
- パラメータは構造体にまとめる。
- 原点の前計算はインスタンスに保持する。

### エラー

| 条件 | エラー |
|---|---|
| \|φ0\| ≥ π/2、scale ≤ 0、または NaN/Inf | `InvalidParams`（new で検出） |
| 入力に NaN/Inf | `InvalidInput` |
| 反復が最大回数で収束しない | `NotConverged` |

## 6. テストベクトル

許容誤差: 順変換 1e-6 m、逆変換 1e-10°。角度は deg で記載。rad に変換して渡すこと。

| # | 入力 (lat, lon) [deg] | φ0, λ0 [deg] | FE, FN | k0 | θ [deg] | 期待値 E, N [m] |
|---|---|---|---|---|---|---|
| 1 | 36.0, 139.0 | 35.5, 139.5 | 0, 0 | 1.0 | 0 | −45082.692369, 55592.468012 |
| 2 | 36.0, 139.0 | 35.5, 139.5 | 1000, 2000 | 0.9999 | 0.5 | −43591.386528, 57978.168560 |
| 3 | 34.7, 135.0 | 34.5, 135.0 | 0, 0 | 1.0 | 0 | 0.000000, 22186.676376 |

追加の検証:

- 上の (E, N) を `inverse` に渡すと、入力の (lat, lon) に戻る。
- 順変換→逆変換の往復誤差が 1e-9° 以下（約 0.1 mm）。
- 原点そのもの（φ=φ0, λ=λ0）が (FE, FN) に写り、逆変換でも戻る。

## 7. 実装上の注意

- 64bit 浮動小数で計算する。
- 原点から数 km〜数十 km の範囲で使う想定。数百 km を超えると投影のひずみが大きくなる。
- 旧 `ReverseFast` に当たる最適化は、インスタンスへの前計算保持と sin/cos の使い回しで実現する。

## 8. 参考: ローカル接平面（ENU）との違い

どちらも原点の接平面に写すが、**何を写すのか**と**どう写すのか**が違う。

### 8.1 変換の性質

| | ローカル接平面（ENU） | Oblique Stereographic（9809） |
|---|---|---|
| 対象 | 3次元空間の点（ECEF）。高さを含む | 楕円体面上の点（緯度・経度）。高さは使わない |
| 方法 | 剛体変換（平行移動＋回転）で ENU にし、U を捨てる | 楕円体を等角球に写し、球の対蹠点を視点とする透視投影で接平面に写す |
| 式の形 | 線形で、閉形式で逆変換できる | 非線形で、逆変換に緯度の反復が要る |
| 角度 | 保存しない。半径方向が縮み、接線方向は縮まない | 保存する（等角）。各点で縮尺が等方的 |

### 8.2 距離のずれ

原点から地表の弧長 d だけ離れた点を、地球半径 R として比べる（c = d/R）。

- **ENU（XY だけ使う場合）**: 平面上の距離は `R·sin(d/R)` で、約 `d − d³/(6R²)`。10 km で約 −4 mm、100 km で約 −4 m。点は接平面から `d²/(2R)`（10 km で約 8 m）だけ下がる。U を捨てることは、この傾きを捨てること。
- **Stereographic**: 平面上の距離は `2R·tan(d/(2R))` で、約 `d + d³/(12R²)`。10 km で約 +2 mm。各点の縮尺は `k ≈ k0(1 + c²/4)` なので、外側ほどわずかに伸びる。

縮尺の符号は反対。Stereographic は `k0 < 1` を選ぶと、現場全体の縮尺の偏りを ± に振り分けて小さくできる（§1 の `scale` パラメータの用途）。

### 8.3 高さの扱い

- ENU の E, N は実際の3次元位置から出る。高さ h の点は、実質的に半径 R+h の面の上で測った距離になり、**地上の距離に近い値**になる。同じ緯度経度でも h によって E, N が変わる。
- Stereographic は楕円体面上の距離（準拠楕円体面上の値に k0 を掛けたもの）。地上の距離に合わせたいときは `k0 ≈ (R+H)/R`（H は現場の平均高さ）として調整する。測量の現場座標系の標準的なやり方。

### 8.4 使い分け

- **ENU**: 3D の測位、レーザー、ロボット、近距離（数 km 以内）で、剛体として扱いたいとき。U を残せば距離は厳密に保たれる。
- **Stereographic**: 地図や図面として角度・方位を保ちたいとき。楕円体の曲率も等角球で取り込んでいるので、数十 km まで精度が落ちにくく、他の投影座標（平面直角座標など）との整合も取りやすい。

まとめると、ENU は空間の点を平面に落とす幾何的な操作（等角ではなく、高さに依存）で、Stereographic は楕円体面を等角に写す地図投影（高さに依存せず、縮尺で調整できる）。
